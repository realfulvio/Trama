# Wine dataset

Aeberhard, S. and Forina, M. (1992). *Wine* [Data set]. UCI Machine Learning Repository. [DOI 10.24432/C5PC7J](https://doi.org/10.24432/C5PC7J).

`wine.data` is the original data file. The tests omit the first column, which identifies the wine cultivar. [Source and metadata](https://archive.ics.uci.edu/dataset/109/wine)
