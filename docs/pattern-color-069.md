# Independent pattern color — 0.69.0

Native rectangles and ellipses can keep their border, background fill and pattern in different colors. In the Appearance page, choose a fill pattern and set Pattern color, or leave it blank to follow the border. The context menu offers Pattern color and Use border color for pattern. Disabling the pattern preserves its confirmed custom color for later reuse; converting the object to a line removes area-only properties.

The optional canonical `hatch_color` property is stored only when explicitly selected. Older records retain their exact dictionaries and rendering. The renderer conditionally uses the public `Patch.set_hatchcolor` API in the pinned Matplotlib 3.11.2, with a single artist per object and no overlays or private backend state. Current color-picker inputs are normalized to RGB so Matplotlib names such as `tab:blue` and alpha hex values do not become invalid Tk chooser colors; cancelling preserves the original stored value.

Color edits use the existing graph-local transaction/history controls and do not change source observations, coordinates or the canvas. The native drawing clipboard preserves the property in compatible versions. Older readers that do not support the property reject it explicitly; custom-pattern projects require a 0.69-capable reader rather than silently dropping their color.
