# Trama 0.80.0 beta — candidate verification

This candidate adds editable hierarchical ZIP-project recipes. Release acceptance is still in progress. This page will be replaced with final native evidence before publication.

Completed checks: 32 focused compatibility/clustering tests; synthetic real-Tk flow at 1024×768, including parameter edits, source edits and exclusions, saved-snapshot independence, `.alab` reopening and CSV/PNG/SVG/PDF exports.

Complete Linux regression and native Windows portable checks are not yet accepted. Native graph appearance uses Trama's renderer; pixel-identical reproduction of every original drawing is not claimed.
