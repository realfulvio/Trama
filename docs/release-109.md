# Trama 0.109.0 beta

- **Cerca comandi.** Apri la ricerca con Ctrl+K e scrivi parte del nome, del menu o della scorciatoia. La lista mostra dove si trova il comando e quando è indisponibile nella vista aperta. Usa le frecce e Invio per eseguire il comando selezionato.
- **Risultati in italiano.** Tradotte le schede di statistica descrittiva, regressione lineare e grafici box/violino. I grafici box/violino mostrano anche le intestazioni tradotte. I nomi usati nei progetti, nei collegamenti e nei dati copiati conservano la forma originale.

Estrai lo ZIP e avvia **Trama.exe** su Windows a 64 bit.

## English

- **Command search.** Press Ctrl+K to search by command name, menu, or shortcut. The list shows where each command lives and whether it is available in the active view. Use the arrow keys and Enter to run the selected command.
- **Italian results.** Descriptive statistics, linear regression, and box and violin plots show Italian results tab labels in the Italian interface. Box and violin plots also show translated column headers. Projects, links, and copied data retain their original names.

Extract the ZIP and open **Trama.exe** on 64-bit Windows.
