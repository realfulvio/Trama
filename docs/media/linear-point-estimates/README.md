# Schermate native Windows

Portabile candidato dalla UI A PR80 più stime lineari. Dati esclusivamente sintetici.

- options-it: campi facoltativi e coordinate con virgola, dopo errori corretti nello stesso dialogo.
- results: risultati puntuali diretti/inversi.
- unbounded: insieme inverso con due componenti illimitate.

linear-ui.json contiene font, scala applicazione, Tcl/Tk e dimensioni effettive del dialogo; display.json è la risoluzione realmente osservata. Nessun DPI di sistema125/150% è stato collaudato. Nessun risultato numerico originale osservato in esecuzione è implicato dalle immagini.

Le catture con suffisso1024 provengono dal collaudo Windows a risoluzione effettiva1024×768. resolution-acceptance.json registra il ritorno alla risoluzione precedente; i DPI di sistema125/150% restano non collaudati.
