# Trama 0.115.0 beta

- **Aggiornamento da CSV e TSV.** Con **File → Aggiorna da file…** puoi scegliere, per ogni riga in conflitto, se mantenere la versione del progetto o usare quella del file. L’anteprima mostra le differenze, comprese le righe eliminate da una delle due parti.
- **Scelte in blocco e tastiera.** Puoi decidere per tutte le righe e cambiare poi le singole scelte. **Successiva da decidere** porta alla prossima riga ancora aperta. **Applica** si abilita quando ogni conflitto ha una decisione.
- **Cronologia del foglio.** Un solo Annulla ripristina i dati e il collegamento precedenti. Le identità e le esclusioni seguono le righe conservate.

Estrai lo ZIP e avvia **Trama.exe** su Windows a 64 bit.

## English

- **CSV and TSV updates.** Use **File → Update from file…** to decide, for each conflicting row, whether to keep the project version or use the file version. The preview shows the differences and identifies rows deleted on either side.
- **Bulk decisions and keyboard controls.** Make a decision for all rows, then revise individual choices. **Next to decide** moves to the next unresolved row. **Apply** becomes available when every conflict has a decision.
- **Worksheet history.** One Undo restores the previous data and link. Row identities and exclusions follow the retained rows.

Extract the ZIP and open **Trama.exe** on 64-bit Windows.
