# Capabilities, verification and remaining work

Trama is a beta Windows application for scientific statistics and figures.
The catalog groups available analysis families; availability of a family does not
imply every possible option or design. There is no audited overall completion percentage.

## Verification records

The [0.99 beta notes](release-099.md) describe the two Classic frontends, clustering diagnostics and worksheet changes. For comparison, the 0.93 beta recorded 2,836 passing unit tests on Linux and 2,835 on native Windows. The Windows test account could not create symbolic links for one check.
See [0.93 validation](validation-093.md) for complete GUI regressions and native portable checks,
[features](features.md), and [format compatibility](compatibility.md).
Tests document particular cases and are not a clinical or regulatory certification.

## Changes in the 0.96 beta candidate

The Qt workspace supports [reusable figure styles](qt-graph-style-presets.md) and [batch export](qt-batch-export.md). Compatible XML projects can recover a one-site binding fit and its linked saturation and Scatchard layout. The observed points and manual line can be edited independently. [Supported import details](compatibility.md).

independent numerical oracles and the permitted sources of external fixtures.
