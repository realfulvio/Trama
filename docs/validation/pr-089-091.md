## Included changes and review corrections

- **#89 Robust curve fit:** Cauchy, Huber and Soft L1 losses, Fixed/Pilot MAD
  scales, parameter editor, residual/weight views and optional ordinary fit.
  Exact pilot now requires genuinely zero computed residuals: representable
  residual variation at large Y offsets must not disappear.
- **#90 Heat-map legends:** Automatic, Fixed and Scientific number formatting,
  0–8 decimal places, canonical saved options and EN/IT controls.
- **#91 Normalize to references:** raw values, replicate series and summaries,
  reference choices and error propagation conditional on the chosen references.
  Unrepresentable aggregate references identify the offending field; graph
  limits include symmetric and asymmetric error extents.
- Failed normalization refreshes retain the previous result with a persistent
  localized warning. Export, PDF selection and Use Result as Data require a
  current result. Retained layout previews remain available; their vector
  export is rejected until recalculation succeeds.
- The analysis dialog uses the decorated Windows frame and monitor work area,
  including the taskbar. Small-screen acceptance computes an attainable client
  viewport rather than requesting a full-screen client plus an extra frame.
- The robust-fit verifier handles array-valued absolute tolerances directly.
  Original expected values and fixtures are unchanged; see the
  [verifier provenance note](pr-089-verifier.md).
