# Acceptance: lognormal one-way ANOVA

**PASS within the scope below.** Runtime source
`2167c36a9af2bf85023fc59e69a6d0238c089180` integrates PR #103 in #105,
including the accepted Q–Q panel editor and ANOVA from summaries. Later merge
and acceptance changes are documentation only. Version remains 0.72.0 beta.

The combined Linux suite passes **2,174 tests**, with no failures or skips,
and the full GUI smoke passes at 1920×1080. The independent verifier passes
**17/17 on Linux and native Windows**. Native Windows passes **155 focused
tests** across the affected statistical modules, dialogs, graph formatting and
Inspector. The extracted portable passes ten workflows: lognormal ANOVA,
Q–Q panels, summary ANOVA, ordinary ANOVA trend and variance-assumption diagnostics,
each at actual 1024×768 and 1920×1080.

An initial harness target used an unsupported selector, which started the full
workflow rather than the intended focused check. That incomplete attempt was
stopped and preserved. Four completed small-screen checks were retained, and
the remaining six ran with recognized selectors on the same saved portable,
after verifying every extracted archive member. No product source changed.

The complete Windows suite and full portable GUI workflow were **not repeated
on this increment**. Their immediately preceding integrated baseline
`47b3404` passed 2,163 native tests and the full portable GUI, recorded in
[the Q–Q/summary acceptance](pr-101-102-104.md). This increment combines a full
Linux regression run with native affected-module tests and all ten focused
portable workflows; it does not claim 2,174 Windows tests.

Review found and corrected an overly restrictive exponential cutoff. Positive
subnormal geometric means, ratios and confidence limits are now retained when
representable; true underflow to zero and overflow still produce the documented
unavailable result. A dispatcher regression failed before the correction and
passed after it, alongside the legacy Normal recipes.

Native English/Italian screenshots were inspected for field focus, scrollable
options, reachable Run/Cancel controls and result tables. The controls are
driven programmatically; this is not a human usability study. System DPI
125/150% was not retested. This method produces tables rather than a graph,
and result headings retain English.

The acceptance task terminated successfully, left no owned application process
and restored 1024×768 at native 96 DPI without registry changes. The saved
portable matches the VM archive and passes ZIP CRC verification. Its checksum
and the exact evidence hashes are in [the machine-readable record](pr-103-105.json).

No release, tag, version bump or repository visibility change is part of this
acceptance.
