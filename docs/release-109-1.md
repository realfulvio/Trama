# Trama 0.109.1 beta

- **Barre d’errore XY.** Nei PZT XML compatibili, la direzione di ciascuna barra resta associata all’osservazione dopo aver spostato, ordinato o inserito righe. Le nuove osservazioni usano la direzione della serie.
- **Fasce ombreggiate nei PZF.** Spostare o ordinare le righe conserva le barre e la fascia collegate ai dati. Le X della fascia devono essere distinte. La vista EMF modificabile conserva le barre visibili del disegno importato.
- **Fogli Info.** Un progetto che contiene solo fogli Info si apre sul primo foglio o su quello attivo salvato, quando disponibile. Se una nota importata è illeggibile, Trama conserva i campi del foglio e segnala quale nota è stata omessa.

Estrai lo ZIP e avvia **Trama.exe** su Windows a 64 bit.

## English

- **XY error bars.** In compatible XML PZT files, each bar keeps its original direction when rows move, are sorted or are inserted. New observations use the series direction.
- **Shaded ranges in PZF files.** Moving or sorting worksheet rows preserves the linked error bars and shaded range. The range requires distinct X values. The editable EMF view preserves the error bars visible in the imported drawing.
- **Info sheets.** An Info-only project opens to its first sheet or the saved active sheet, where available. If an imported note is unreadable, Trama keeps the sheet fields and identifies the omitted note.

Extract the ZIP and open **Trama.exe** on 64-bit Windows.
