# Trama 0.116.0 beta

- **Tabelle su grafici e layout.** Con **Disponi → Seleziona / sposta tabelle** puoi trascinare una tabella collegata o una copia. Le frecce permettono aggiustamenti fini. Ogni spostamento confermato è un passo di Annulla. I pannelli di un layout conservano la loro posizione.
- **Regressione lineare multipla.** Il [test di mancato adattamento con repliche](replicate-lack-of-fit.md) confronta lo scarto del modello con la variabilità fra osservazioni che condividono tutti i predittori. L’opzione è in **Diagnostica e previsioni** per i modelli lineari senza pesi.

Estrai lo ZIP e avvia **Trama.exe** su Windows a 64 bit.

## English

- **Tables on graphs and layouts.** Choose **Arrange → Select / move tables** to drag a linked table or a copy. Use the arrow keys to fine-tune its position. Each confirmed move is one Undo step. Layout panels keep their positions.
- **Multiple linear regression.** The [replicate lack-of-fit test](replicate-lack-of-fit.md) compares model error with variation among observations that share all predictors. Find it under **Diagnostics and predictions** for unweighted linear models.

Extract the ZIP and open **Trama.exe** on 64-bit Windows.
