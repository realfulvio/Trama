# Trama 0.111.0 beta

- **Formato dei risultati.** In Opzioni, imposta le cifre significative e scegli come mostrare i valori p nell’ANOVA multifattoriale, nei test t standard, nella regressione non lineare e in Kaplan–Meier. Le tabelle possono mostrare decimali fissi, asterischi o entrambi.
- **Progetti compatibili.** Le ricette importate dei metodi supportati recuperano le cifre significative e lo stile valore p con asterischi quando sono salvati nel file.
- **Stampa e dati.** La stampa usa il formato visibile. Copia, export dei dati e calcoli continuano a usare i risultati numerici.

Estrai lo ZIP e avvia **Trama.exe** su Windows a 64 bit.

## English

- **Result formatting.** Set significant digits and p-value presentation in Options for multifactor ANOVA, standard t-tests, nonlinear regression and Kaplan–Meier. Tables can show fixed decimals, significance stars or both.
- **Compatible projects.** Imported recipes for supported methods restore significant digits and the p value with stars style when saved in the file.
- **Printing and data.** Printing uses the displayed format. Copy, data export and calculations continue to use numeric results.

Extract the ZIP and open **Trama.exe** on 64-bit Windows.
